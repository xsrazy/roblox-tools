Getting started

Is it really free?

Yes. Every tool is free, with no premium tier and no locked features. That includes the extras people usually pay for elsewhere, like downloading your profile card as a PNG from the Account Checker.

Do I need a Roblox account to use it?

No. You don't sign in to anything, and you never type a password here. The tools only read public profile data, the same info anyone can see on roblox.com. If a site ever asks for your Roblox password or cookie to do a lookup, close the tab.

Is this site affiliated with Roblox?

No. It's a fan-made tool site built by one person. All data comes from Roblox's public APIs. More on that on the About page.

Reading your results

Why does RAP show a dash for some users?

RAP needs the inventory to be public. If someone sets their inventory to private, Roblox hides their collectibles and there is no RAP to show. Nothing anyone can do about that one. Quick way to confirm: run the RAP Checker again in a minute. If it still shows a dash while the rest of the profile loads fine, the inventory is private, it is not a bug. The RAP guide on the blog explains the number itself.

Why do my outfits or friends list come up empty?

Usually a privacy setting on that account, or Roblox being slow for a moment. Wait a few seconds and try again, the outfit tools already retry on their own when Roblox answers with an empty list. Then check the same profile on roblox.com. If it shows empty there too, the account really has nothing saved. A brand new account with zero outfits looks exactly like that, and it is a real result, not an error.

Can you check a banned account?

Public basics like the join date still show for most banned accounts, and the card marks the account as banned. Anything Roblox itself hides stays hidden, including most inventory data.

Problems and your data

Why does a tool say temporarily unavailable?

Six tools (Friends List, Mutual Friends, Followers, Following, User Badges and Avatar 3D) run through a helper account session, because Roblox gates those lists. If that session drops, those six pause and say so honestly instead of showing wrong data. The other 43 tools keep working. The Status page checks each group live, so you can see which side is having the bad day.

What happens to the usernames I check?

They show up on the Recently looked up page, together with the tool you used. That is all. We don't build profiles of visitors, and the tracker list in the User Tracker never leaves your own browser. The Privacy Policy spells it out.
