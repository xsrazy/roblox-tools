The password rule: no legit tool ever asks for it

Safety · 5 November 2026 · 2 min read

A username is all a lookup needs

Everything on a public Roblox profile, the avatar, friends count, followers, RAP, outfits, badges, is readable with just a username. That is how every tool on this site works. No sign-in, no account, nothing typed in that could be stolen.

The red flags

Any site that asks for your Roblox password is not a lookup tool, it is a trap. Same story for sites asking you to paste a cookie or a security token. Those hand over your whole account, Robux, limiteds and all, to a stranger.

What we ask for here

Nothing. There are no accounts on this site and no login form anywhere. The only thing you ever type is a username or an ID into tools like the Account Checker. If that ever changes, we will say so loudly on the Changelog first.

One habit worth keeping

Before using any fan tool, ask one question: could this work with public data alone? If yes, it should never need your credentials. If it still asks, walk away.
