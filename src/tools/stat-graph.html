Stat Graph

Chart the current public stats of a Roblox account as bars. Add a second username to compare both accounts in grouped bars.

Honest note: the original version of this kind of graph charts badge progression, but Roblox does not publish badge history publicly (the badges API requires login), so this page charts current public stats instead, using only real values returned by this site's own API.

Result

Counts: friends, followers, following

RAP (separate scale)

RAP is charted separately because its values are far larger than friend and follower counts and would flatten the chart above.
