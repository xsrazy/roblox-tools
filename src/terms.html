Free to use

You can use every tool on this site for free. There is no premium tier, no locked features and no sign up.

The data

The data shown comes from Roblox's public APIs. We show it as it comes; numbers like RAP and item prices move in real time, so a figure can be slightly out of date the moment you see it. If a number looks wrong, the Status page tells you whether the lookup itself is healthy right now.

Play fair

Please don't hammer the site with bots or automated bulk lookups. If you need lots of data, Roblox's own APIs are right there.

Things can change

Tools can change or be removed at any time. Six of them depend on a helper session and may pause without notice; the rest run on public APIs. When something big changes, it lands on the Changelog, with a version number and a date.

Not affiliated

This site is not affiliated with Roblox Corporation, and nothing here is an official Roblox product.
